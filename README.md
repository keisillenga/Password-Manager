#  Password Manager

A simple **Password Manager** built with Python that allows users to securely organize and manage their passwords through a command-line interface.

The application uses JSON to store password information locally and includes a built-in password generator for creating random, strong passwords.

##  Features

- **Add Passwords** – Save website names, usernames, and passwords.
- **Generate Passwords** – Automatically generate random passwords.
- **View Passwords** – Display all saved login information.
- **Search Passwords** – Find saved credentials by website name.
- **Delete Passwords** – Remove stored website credentials.
- **JSON Storage** – Save password data in a local JSON file.
